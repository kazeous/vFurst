vFurst exposes organizer-owned convention data through scoped API keys and signed outbound webhooks.

1. Create an organization in the dashboard.
2. Complete Stripe Connect before opening paid sales.
3. Create an API key with the narrowest required scopes.
4. Configure webhook endpoints for event-driven integrations.
5. Use the billing dashboard to reconcile collected platform fees.

Local development uses the same Postgres, Redis, MinIO, and Mailpit stack described in the main repository plan.
